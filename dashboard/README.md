# Checky : Advanced Task Management System

A comprehensive, enterprise-grade task management system featuring a modern admin dashboard, real-time analytics, and efficient user/task coordination. Built with Next.js for high performance and premium aesthetics.

Developed by **Md Shakil Hossain**.

---

## 🏗️ Core Architecture

This project follows a **modular, feature-based architecture** designed for high scalability and maintainability.

### **Key Modules**
1. **Admin Intelligence**
   - Full CRUD operations for users and tasks.
   - Real-time system analytics and status distributions.
   - Comprehensive audit logging for security and tracking.

2. **User Workspace**
   - Personalized task management and tracking.
   - Profile customisation and secure account settings.

### **Shared Resources**
- **UI Architecture**: Custom-built on Shadcn/UI with a premium monochromatic blue theme.
- **API Strategy**: Centralized Fetch-based service layer with automated re-authentication.
- **Type Safety**: End-to-end TypeScript integration for robust development.

## 🚀 Getting Started

### Environment Variables
Create a `.env.local` file in the root directory:

```env
# API Configuration
NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1

# Quick Demo Credentials
# Admin: admin@tasksystem.com / admin123
# User: user@tasksystem.com / user123
```

### Installation & Run

```bash
# Install dependencies
bun install

# Start Development Server
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to access the dashboard.
